# 英语小勇士 · 拼读闯关

小学 1–3 年级英语单词游戏。共享词库、独立游戏页、5 分钟门禁题型三层，和「唐诗小状元」的接法一致。

## 目录

```
english/
├── english-data.js    词库 + 出题器（328 词，游戏与门禁共用）
├── english.html       游戏页面
├── english.css        页面样式
├── english.js         关卡、判题、进度、词库浏览
└── README.md
gate/challenges/english.js   门禁题型（依赖 english-data.js）
```

## 词库元数据

每个单词一条记录：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| `w` | 单词 | `apple` |
| `zh` | 中文意思，多义用「；」 | `苹果` |
| `g` | 难度级别，1/2/3 对应一/二/三年级 | `1` |
| `c` | 主题分类（30 类） | `食物` |
| `ipa` | 音标 | `/ˈæpl/` |
| `syl` | 音节拼读，用 `-` 切分 | `ap-ple` |

共 328 词：一年级 115、二年级 102、三年级 111。按人教版/外研版小学常见词汇与主题整理，不严格对应某一册教材；新增单词只需要在 `english-data.js` 的 `words` 数组里加一行。

`EnglishData.phonicsHint(word, ipa)` 会结合拼写与音标给出拼读提示（sh / ch / th / oo / ee / ea / ai / ou / ar / or / ir / ur / 词尾 -er / 词尾 e / 双写辅音等）：先看单词里的字母组合是否真的出现在音标中，再决定这条规则说不说，避免「our 里读出 ur」这类误导，不用为每个单词单独写规则。

## 出题器

```js
EnglishData.makeQuestion(type, {
  grades: [1, 2],        // 出题范围
  exclude: ["apple"],    // 本轮已经出过的单词
  random: Math.random
});
```

| type | 模式 | 题面 | 答案 |
| --- | --- | --- | --- |
| `en2zh` | 四选一 | 英文单词 + 音标 + 音节 | 中文意思 |
| `zh2en` | 四选一 | 中文意思 | 英文单词 |
| `zh2en-write` | 手写拼写 | 中文意思 + 首字母 + 字母数 | 完整单词 |
| `fill-choice` | 四选一 | 单词前半段 + 空格 | 缺的后半段 |
| `fill-write` | 手写补全 | 单词前半段 + 空格 | 缺的后半段 |

干扰项优先取同主题、长度接近的词；中文意思重复的词（如 bye / goodbye）会自动去重，保证四个选项不重复。补全题只收纯字母、长度 ≥ 4 的词（避开 T-shirt 这类带连字符的词）。

## 八个关卡

每关 10 题，**第一次答对 8 题**过关；10 / 9 / 8 题分别对应 3 / 2 / 1 颗星。

每轮开始时会按本关题型生成一张题型表：各题型数量尽量均分，并保证相邻两题不重复，不会出现 10 题全是同一题型。自由练习的选择题 / 手写 / 补全组合同样走这张表。

| 关 | 名称 | 范围 | 题型 |
| --- | --- | --- | --- |
| 1 | 认识新词 | 一年级 | 英翻中 + 中翻英 |
| 2 | 中英配对 | 一年级 | 中翻英 + 补全 + 英翻中 |
| 3 | 补全单词 | 一、二年级 | 补全（选择 / 手写）+ 英翻中 |
| 4 | 二年级词库 | 二年级 | 英翻中 + 中翻英 + 补全选择 |
| 5 | 动手拼写 | 二年级 | 拼写 + 补全（手写）+ 英翻中 |
| 6 | 三年级词库 | 三年级 | 三种选择题 |
| 7 | 三年级拼写 | 三年级 | 拼写 + 补全（手写）+ 中翻英 |
| 8 | 终极挑战 | 全年级 | 五种题型混合 |

- 解锁：通过第 N 关才解锁第 N+1 关；进度存 `localStorage`（键 `shutu.english.v1`，只记 `{best, stars, plays}`，解锁状态由连续通关推导）。
- 自由练习：可选年级（全部/一/二/三）与题型（混合/选择题/手写/补全），10 题一轮，不计入闯关进度。
- 单词表：按年级筛选、按单词/中文/主题搜索，每行可点 🔊 用浏览器语音朗读。
- 每题可点「给点提示」，只给拼读规则与首字母，不直接给答案。
- 每题只有一次提交机会；答错立即公布完整单词、音标、音节与拼读，下一题继续。这样 8/10 的门槛才有意义。
- 0 分且从未通关时不留关卡记录，首页不会出现「最好 0/10」；完整玩完一关计入一次局数（`GameLimit.count()`），自由练习不计。

## 调试

- `english.html?level=3`：直接进入第 3 关（跳过关卡锁，便于测试）。
- `english.html?practice=1`：直接开一轮全年级混合练习。
- `window.EnglishGame.state`：当前题目、分数、已出单词列表、本轮题型表 `typePlan`。
- `window.EnglishGame.startPractice("all", "write")`：按「全部年级 + 手写」直接开一轮练习，便于测试。

## 作为 5 分钟门禁题型

`gate/challenges/english.js` 注册 id `english`，从三个年级随机抽 `en2zh` / `zh2en` / `fill-choice` 四选一；答对调用 `api.pass()`，答错公布答案并停留 8 秒后自动换题，不能跳过。

已接入：俄罗斯方块、枪战游戏、草坪守卫战、穿云战机、霓虹狂飙、钢铁防线（各页面已引入 `english/english-data.js` 与 `gate/challenges/english.js`，并把 `'english'` 加进 `challenges` 数组）。

调试某个游戏的门禁题型：

```
tetris/tetris.html?tf24demo=1&gate=english
```

样式统一放在 `gate/challenges.css` 的 `.chen-*` 段，跟随门禁的深咖啡主题。
