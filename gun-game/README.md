# 铁幕街区 · 8 关战术射击

俯视角战术射击小游戏。玩家要在 8 个连续的夜间行动里，利用视野、噪音和掩体，决定是无声潜入还是正面强攻。

## 核心体验

- **视野就是生命线**：墙、木箱、油桶都会挡住视线，也会挡住子弹。探索过的区域会被记在战术地图上，但敌人只在你的视野内显形。
- **枪声会叫人**：消音手枪噪声半径小，适合点名和近身处决；冲锋枪、霰弹枪、精确步枪会把整层楼的敌人引过来。
- **敌人会打战术**：巡逻 → 警觉 → 追到最后目击点 → 搜索 → 冷静；会横向游走、残血找掩体，重装兵正面有盾，狙击手开火前会亮红色激光，指挥官会召增援。
- **环境能杀人**：手雷、油桶连锁爆炸、可打穿的木箱，都是进攻工具。
- **战后有成长**：每关结束按时间、命中、潜行、警报、击杀给出 S/A/B/C 评级，获得信用点；在战前整备里买武器、永久强化和下一局补给。

| OP.01 仓库清点 | 城郊废弃仓库 | 清剿 5 名守卫后撤离 | 教学：视野、掩体、处决、消音枪 |

## 敌人与武器

- 敌人：步枪兵、突击兵（冲锋）、狙击手（激光预警）、重装兵（正面减伤 62%）、指挥官（加速射速并召唤增援）、Boss「铁颚」（正面装甲 70%，半血进入二阶段）。
- 武器：MK23 消音手枪、MP5 冲锋枪、霰弹枪（8 弹丸）、精确步枪（穿透 1 个目标）。
- 强化：伤害、换弹速度、移动速度、生命、护甲，均为永久成长；补给只作用于下一局。

## 运行方式

页面是纯静态的，直接用浏览器打开 `gun-game.html` 即可。若浏览器限制了本地文件，可在项目根目录启动一个静态服务：

```bash
cd /Users/tiltwind/workspace/shutu
python3 -m http.server 8123
# http://127.0.0.1:8123/gun-game/gun-game.html
```

## 调试参数

- `?mission=m1&start=1`：直接进入指定关卡。
- `?unlock=1`：临时解锁全部关卡（只影响本次运行，不写存档）。
- `?nogate=1`：关闭站内 24 点 / 古诗门禁，方便连续测试。

控制台可用的测试接口：`GG.Game.start(id)`、`GG.Game.world()`、`GG.Game.profile()`、`GG.Game.state()`、`GG.Game.debug()`。

## 存档

- 进度：`localStorage["shutu.gun-game.v2"]`，保存信用点、关卡评级、武器解锁、强化等级、携带武器、难度与补给。
- 静音：`localStorage["shutu.gun-game.v2.mute"]`。
- 站内游玩次数由 `../limit/limit.js` 统一管理，每完成 1 关计 1 次，4 次后进入 30 分钟休息。

## 关卡校验

```bash
cd /Users/tiltwind/workspace/shutu/gun-game
node tools/validate-levels.js
```

脚本会检查每关房间/走廊是否连通、敌人和终端是否落在可行走格、撤离点与波次点是否存在，并输出每关的规格摘要。
