# 草坪守卫战（植物大战僵尸风格塔防）

入口：`pvz.html`。纯静态页面，双击即可运行，无需构建、无外部依赖（音效全部用 WebAudio 现场合成）。

## 目录结构

```
pvz/
├── pvz.html              页面骨架：canvas + HUD 静态节点 + 弹窗容器
├── css/style.css         全部界面样式（含 760px / 480px 两档响应式）
├── assets/               落地素材（14 张，已抠透明底）
│   └── source/           素材原图，便于重新处理
├── js/
│   ├── config.js         ★ 全部数值：画布/网格/阳光/植物表/僵尸表/章节/12 关
│   ├── util.js           数学、格子↔像素换算、事件总线、localStorage 存档
│   ├── audio.js          WebAudio 合成音效库（击打类 12 种 + 反馈类 10 种）
│   ├── assets.js         图片预加载清单
│   ├── entities.js       Plant / Zombie / Projectile / Sun / Particle / Mower
│   ├── world.js          一局战斗的权威状态：经济、冷却、波次、命中、胜负
│   ├── render.js         全部 Canvas 绘制（只读，不改逻辑）
│   ├── hud.js            DOM 界面：种子卡、波次条、各类弹窗
│   ├── game.js           主循环、输入、选卡铲子、关卡流程、星级
│   ├── app.js            启动、预加载、开始页
│   └── tools/prepare_assets.py  素材批处理脚本（抠图 + 裁边 + 统一高度）
└── _work/                中间产物（抠图中间件、核对图、废弃背景）
```

依赖顺序即 `pvz.html` 底部脚本顺序：config → util → audio → assets → entities → world → render → hud → game → app。全部挂在 `window.PVZ` 命名空间下，无模块打包器要求。

## 扩展方式

- **加植物**：在 `config.js` 的 `PVZ.PLANTS` 加一条（`kind` 决定行为分支），`entities.js` 里补对应分支，`assets.js` 清单加图，关卡 `unlock` 里放进去。
- **加僵尸**：`PVZ.ZOMBIES` 加一条，素材命名 `zombie_xxx.png` 并在 `assets.js` 里注册 `z_xxx`；特殊行为（跳、啃、召唤）在 `entities.js` 的 `Zombie.update` 里按 `def` 字段分派。
- **加关卡 / 调难度**：`PVZ.LEVELS` 一条一个关卡，`waves[].groups:[类型, 数量, 出生间隔]`；难度四件套 `speedMul`（速度）、`hpMul`（血量）、`sunStart`/`sunInterval`（经济）、`cooldownMul`（种植冷却）。第 12 关额外支持 `boss` 配置。
- **加音效**：`audio.js` 的 `play()` switch 里加一个 case，用 `tone()`/`noise()` 组合即可，无需音频文件。
- **加章节**：`PVZ.CHAPTERS` 加一条，只靠 `tint + darkness + gridAlpha` 在同一张背景上换氛围。

## 升级链

不选种子卡时，直接点击场上已经种下的植物即可花阳光升级，头顶出现金色小箭头就代表阳光够了。

| 植物 | 一级升级 | 二级升级 |
| --- | --- | --- |
| 豌豆射手 | 双发豌豆 · 125 阳光（每 1.0s 两发） | 三发豌豆 · 175 阳光（每 0.85s 三发） |
| 向日葵 | 双生向日葵 · 125 阳光（产出间隔 11s→7s） | — |
| 坚果墙 | 钢铁坚果 · 100 阳光（血量 ×2.2） | — |
| 卷心菜投手 | 重型卷心菜 · 150 阳光（伤害 60→100） | — |
| 狙击枪射手 | 穿甲狙击枪 · 200 阳光（伤害 90→180） | — |

升级数据写在 `config.js` 每种植物的 `upgrades` 数组里，数组第 N 项就是第 N 次升级，改数值或加一级都不用动代码。豌豆射手基础伤害已从 20 翻倍到 40。

## 关卡规则与背景音乐

- **一关最多打两次**：每关的通关次数记在存档 `clears` 里，通过两次后该关锁定，再点会弹「已通关两次」，主按钮直接跳到下一关。选关页上这类关卡会显示「已通关 ×2」，通关弹窗也会收起重玩按钮。
- **背景音乐**：`audio.js` 用 WebAudio 现场合成，一段 32 音的循环旋律加低音根音，无音频文件。进关淡入、暂停/通关/回选关淡出；顶栏「音乐」按钮单独控制，与「音效」互不影响，开关状态存进存档。

## 难度调节

当前 12 关的难度已整体下调到原始设计的一半左右，落点是四组数据：`speedMul`（僵尸速度）、`hpMul`（僵尸血量）、`cooldownMul`（种植冷却）三者的超出基准部分减半，加上每波 `groups` 里的数量与出生间隔（数量 ×0.65、间隔 ×1.2），同时 `sunStart` +35、`sunInterval` −3。想再调松紧，直接改这几个字段即可，无需动代码。

## 操作
鼠标/触屏点阳光收集，点种子卡再点草坪种植；铲子可撤掉一格；数字键 1-7 选卡、Esc 取消、P 暂停。每行最左一台割草机，每关每行只救一次。撑过全部波次且场上清空即过关，损失植物数量与用时决定 1-3 星。
